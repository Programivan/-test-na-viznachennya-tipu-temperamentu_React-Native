# Додаток «Визначення темпераменту користувача»

Практична робота з курсу **«Developing Mobile Apps Using React Native»** (IT STEP Academy).  
**Тема:** `Alerts. Components`.

---

## 📌 Опис проєкту

Додаток призначений для психологічного тестування та визначення домінуючого типу темпераменту людини:
- ☀️ **Сангвінік**
- 🌙 **Меланхолік**
- 🔥 **Холерик**
- 🌿 **Флегматик**

### Реалізований функціонал:
1. **Кнопка «Старт»**: починає тестування та ініціює послідовне опитування.
2. **Використання `Alert`**: кожне питання задається через нативне діалогове вікно `Alert.alert` із кнопками відповіді **«Так»** та **«Ні»**.
3. **Компонентна архітектура**: додаток розбитий на модульні компоненти:
   - `Header.js` — шапка додатку з інформацією про тему.
   - `StartScreen.js` — початковий екран з описом усіх 4 типів темпераменту та кнопкою «Старт».
   - `QuestionCard.js` — екран активного запитання з прогрес-баром, лічильником запитань та кнопками.
   - `ResultScreen.js` — детальний екран результатів з описом переважного темпераменту, ключовими рисами, порадами та діаграмою розподілу всіх 4 типів у відсотках.
   - `CustomAlertModal.js` — кросплатформна підтримка інтерактивних алертів для Web-версії.
4. **Підсумок**: після завершення тесту виводиться фінальний `Alert` із результатом та відкривається екран із повною статистикою та можливістю пройти тест повторно.

## 🚀 Як запустити проєкт

Переконайтеся, що ви знаходитесь у папці проєкту (`react-native`):

### 1. Запуск через Expo (універсальний)
У терміналі виконайте:
```bash
npm start
```
або
```bash
npx expo start
```

### 2. Варіанти перегляду:
- **У веб-браузері (найшвидше)**:  
  Після запуску `npm start` натисніть у терміналі клавішу `w` (або запустіть `npm run web`).
- **На реальному смартфоні (Android / iOS)**:  
  1. Встановіть безкоштовний додаток **Expo Go** з Google Play або App Store.
  2. Відкрийте камеру або Expo Go та відскануйте QR-код, який з'явиться в терміналі.
- **В емуляторі Android**:  
  Після запуску `npm start` натисніть клавішу `a` (або `npm run android`).

## 📁 Структура файлів

```
react-native/
├── App.js                         # Головний компонент додатку та логіка тестів
├── src/
│   ├── components/
│   │   ├── Header.js              # Шапка додатку

│   │   ├── QuestionCard.js        # Відображення поточного питання і прогресу
│   │   ├── ResultScreen.js        # Екран результату та відсотковий баланс
│   │   └── CustomAlertModal.js    # Кросплатформне модальне вікно для веб-версії
│   └── data/
│       └── questions.js           # База запитань та опис темпераментів
├── package.json
└── app.json
```
